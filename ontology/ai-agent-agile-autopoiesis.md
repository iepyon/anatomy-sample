# AIエージェント前提のアジャイル：オートポイエーシス版オントロジー

旧版（五つの作業台の回転台として図にしたもの）を描き直した版です。図はこの文書が固まってから作ります。

## 0. 描き直した理由

旧版は「仕事を加工して、外に学びを積む機械」でした。オートポイエーシスの言葉で言えば、自分以外のものを作る系（アロポイエーシス）です。具体的には次の3点がずれていました。

| 旧版 | 何がずれていたか |
|---|---|
| 確認の許容範囲は封印され、人にもAIにも動かせない | 何を「良い」とするかが外から与えられている。自律した系は自分の存続の条件を基準に判断する（Froese & Ziemke 2009 は、外から価値関数を与えられた主体は真の主体になれないと批判している） |
| 学びは環境側の柱に積まれる | 作ったものが自分の外に出ていく。オートポイエーシスでは、産出されたものが産出のネットワーク自身と境界を作り直す |
| 合格が3回続くと、人が鍵を回して観測範囲と実行権限が一段上がる | 系の形が外から段階的に与えられている。部品が壊れることも、作り直さなければ消えることも描かれていない |

## 1. 土台にした理論

| 用語 | 意味 | 出典 |
|---|---|---|
| オートポイエーシス（自己産出） | 構成素を産出するプロセスのネットワークで、構成素がその相互作用によってネットワーク自身を作り直し、それを一つのまとまりとして区切る | Varela, Maturana & Uribe 1974 |
| 境界の自己産出 | 境界（膜）はネットワークが作り、ネットワークは境界に守られて続く。境界は外の材料を通すが、中の働きは外に出さない | 同上の最小モデル |
| 組織と構造 | 組織＝変わらない関係のパターン。構造＝その時々の具体的な部品。部品がすべて入れ替わっても組織は保たれうる | Maturana & Varela 1987 |
| 作動的閉鎖 | 系の作動は自分の作動にしかつながらない。外とつながるのは材料のやりとりと撹乱だけ | 同上 |
| 構造的カップリングと撹乱 | 環境は変化のきっかけ（撹乱）を与えるが、何が起きるかは系自身の構造が決める。外からの「指示」は成り立たない | 同上 |
| 不安定性（precariousness） | 互いを成り立たせる関係が一つでも欠けると組織は崩れる。だから作り直し続けなければならない | Di Paolo 2005、Froese & Ziemke 2009 |
| 適応性（adaptivity） | 存続の条件に照らして、自分と環境とのやりとりを調整する力。これがあって初めて「意味づけ」が生まれる | Di Paolo 2005 |
| 組織＝決定のオートポイエーシス | 社会システムとしての組織の要素は「決定」で、組織は決定によって決定を産み、決定の前提（決定前提）を自分で作る | Luhmann『組織と決定』 |
| スクラムは閉じた系 | スクラムを自己組織的に安定する閉じた系と見ると、統制は間接的になり、自己拘束を促す力が鍵になる | Lies 2020 |

注意：生物学の厳密な意味では、ソフトウェアのエージェントは自分の物質を作らないので、オートポイエーシス系ではありません。この文書では、ルーマンの社会システム論と Froese & Ziemke の設計原則に従い、**「決定」を要素とする協働の系**を単位とし、その作動的閉鎖を設計の目標として扱います。

## 2. 単位：何がオートポイエーシス的なのか

**単位は「協働系」**です。人とAIエージェントが同じ記録の上で決定を重ねる系で、エージェント1体ではありません。

- **要素**：決定。一つの決定は、それまでの決定を前提にしてのみ起こる。
- **構成素**：決定前提。決定から産まれ、次の決定を制約する。
- **境界**：いま効いている決定前提の集まり。何が見え、何ができ、何を「済み」と呼ぶかを決める。境界の外は、系にとって存在しない。
- **環境**：境界の外のすべて。利用者、市場、コードベース、他のチーム、他のエージェント、モデル提供者。

## 3. 概念（クラス）

### 3.1 作動：産出のネットワーク
五つのプロセスが輪になり、それぞれが他のプロセスに必要な構成素を作ります。どれか一つが止まると全体が止まります（不安定性）。

| プロセス | 使う構成素 | 作る構成素 |
|---|---|---|
| 知覚 Perceive | 観測範囲 | 観測（撹乱を系の言葉に変えたもの） |
| 解釈 Interpret（旧「考え」） | 観測、記憶、技能 | 意図（次に何をするかの決定） |
| 実行 Act | 意図、実行権限 | 作用（環境への働きかけ） |
| 確認 Verify | 作用の結果、検証基準 | 判定（存続の条件に照らした良し悪し） |
| 再産出 Reproduce（旧「反映」） | 判定、記録 | 観測範囲・実行権限・検証基準・技能・記憶の更新 |

再産出が作ったものを、知覚・解釈・実行・確認が使います。これで輪が閉じます（作動的閉鎖）。

### 3.2 構成素：決定前提
すべて系自身の決定によって作られ、放っておくと失効します。

| 構成素 | 何を決めるか | 失効のしかた |
|---|---|---|
| 観測範囲 Scope | 何が見えるか。境界の「知覚の面」 | 見ている対象が変わり、範囲が実態とずれる |
| 実行権限 Authority | 何に手を出せるか。境界の「作用の面」 | 期限切れ。権限が使われず、信頼の根拠が古くなる |
| 検証基準 Criteria | 何を「良い」「済み」とするか（完成の定義を含む） | 環境が変わって基準が的外れになる |
| 技能 Skill | どうやるか（手順、ツールの使い方、プロンプト） | 道具や前提が変わって動かなくなる |
| 記憶 Memory | 何を前提にするか（知識、経緯） | 古くなる、矛盾が溜まる |

### 3.3 境界
- 境界は、上の五つの構成素の集まりそのものです。
- **境界は系が作る**：誰かが外から引いた線ではなく、再産出の結果として毎回引き直される。
- **境界は半透過**：材料（情報、要求、コード、データ）は入ってくるが、系の作動（決定のつながり）は外に出ない。外に出るのは作用だけ。

### 3.4 環境とのつながり
| 概念 | 定義 |
|---|---|
| 撹乱 Perturbation | 環境からの刺激。人の依頼、障害、市場の変化、他エージェントの出力を含む。何が起きるかは系の構造が決めるので、依頼も「指示」ではなく撹乱として扱う |
| 構造的カップリング | 系と環境が互いを撹乱し合う関係が続くこと。共有の記録、人とのやりとり、デプロイ先がその場になる |
| 材料 Substrate | 境界を通って入り、構成素の材料になるもの |
| 作用 Effect | 系から環境への働きかけ。環境にとっての撹乱 |

### 3.5 存続の仕組み
| 概念 | 定義 |
|---|---|
| 存続条件 Viability | 輪が回り続けるための条件（構成素の鮮度、材料の流入、判定が意味を持つこと） |
| 適応性 Adaptivity | 存続条件に近づいたら、自分のやりとりを調整する働き。例：検証の不合格が続いたら観測範囲を狭めて材料を選ぶ、権限を自分で縮める |
| 組織 Organization | 変わらないもの：五つのプロセスが互いの構成素を作り合う閉じた関係 |
| 構造 Structure | 変わるもの：いま効いている具体的な構成素。すべて入れ替わってもよい |
| 構造的ドリフト | 撹乱と再産出の積み重ねで構造が変わっていくこと。外から見ると「適応」や「学習」に見える |
| 崩壊 Dissolution | 再産出が失効に追いつかなくなり、境界が保てなくなること |

### 3.6 記録：改ざんできないもの
旧版の「封印された許容範囲」は、場所を変えて残します。**封印するのは基準ではなく記録です。**
- 検証基準は系が自分で作り直す構成素なので、封印しない。
- 何を観測し、何を決め、どう判定したかの記録は追記のみで、人にもAIにも書き換えられない。
- 再産出は記録を材料にする。だから、系は過去を作り替えて自分に都合のよい境界を引くことができない。

### 3.7 人の位置
- 人とのやりとり（依頼、承認、レビュー）は、協働系の中の決定として記録に残る。その範囲で人は系の作動に参加する。
- 人が外から系を直接書き換えることは、この存在論では起こらない。それは撹乱であり、系が自分の構造に従って受け止める。
- 実行権限の拡大も、外から与える「鍵」ではなく、人の承認を含む系自身の決定として産出される。

## 5. 旧版との対応

| 旧版 | 新版 | 変わったこと |
|---|---|---|
| 知覚の頭と光の輪（観測範囲） | 知覚 ＋ 構成素「観測範囲」 | 輪は外から与えられた範囲ではなく、系が作る境界の一部になる |
| 考え（モデルの箱） | 解釈 | 記憶と技能という自前の構成素を使う |
| 実行のプレス | 実行 ＋ 構成素「実行権限」 | 権限も系が作り、失効する |
| 封印された確認ゲージ | 確認 ＋ 構成素「検証基準」＋ 改ざんできない記録 | 封印は基準から記録へ移る |
| 反映（学びを環境の柱へ） | 再産出 | 学びは外に積まれず、自分の境界と構成素を作り直す |
| 体のダイヤル（3連続合格で一段、人が鍵） | 適応性 ＋ 構造的ドリフト | 段階的な昇格ではなく、作り直しと失効の釣り合いで形が決まる |
| 共有記録のケーブル | 記録 ＋ 構造的カップリング | 参加者をつなぐ場であり、再産出の材料 |
| 柱が10層で満ちて終わる | 崩壊 | 終わりは「満ちる」ことではなく、作り直しが追いつかなくなること |

## 6. 判定：この協働系はオートポイエーシス的か

Varela らの手順にならい、観察者が確かめる問いとして置きます。

1. 境界が識別できるか → いま効いている決定前提の集まりとして、列挙できる。
2. 構成素が識別できるか → 観測範囲・実行権限・検証基準・技能・記憶。
3. 構成素は、構成素どうしの関係から作られるか → 再産出が、判定と記録から作る。
4. 境界の構成素も、同じネットワークが作るか → 観測範囲と実行権限は境界そのもので、再産出が作る。
5. 構成素が失効し、作り直されているか → 各構成素に失効のしかたがあり、作り直されなければ境界がやせる。
6. 外からの指示なしに、組織が保たれているか → 依頼も承認も系の中の決定として扱い、外から構成素を直接書き換えない。

どれか一つでも「いいえ」になる運用（基準を外から固定する、権限を外から付け外しする、記録を書き換える）は、アロポイエーシスへ戻ります。

## 7. 図にするときに見せるべきこと

次の図は、少なくとも次の6点を、物の動きとして見せます。

1. 中の働きが、自分を囲む境界の部品を作っていること。
2. 境界の部品が劣化して崩れ、作り直されていること。
3. 部品がすべて入れ替わっても、同じ境界が保たれていること（組織と構造の違い）。
4. 外からは材料と撹乱だけが入り、何が起きるかは中が決めていること。
5. 材料が途切れると作り直しが追いつかず、境界がやせて崩れていくこと（不安定性）。
6. 記録だけは書き換えられずに残り続けること。
