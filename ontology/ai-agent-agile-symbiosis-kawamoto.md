# AIエージェントと人の共生：河本英夫の観点によるオントロジー（第4版）

ルーマン版（第3版）は「決定のコミュニケーション」を要素とし、人もAIも系の外に置きました。この版は河本英夫の**第三世代システム**（作動・行為存在論・二重作動）の観点で、人とAIエージェントの**カップリングが作る共生系**を単位にし、その産出を **a → b → c → a** の循環として描きます。

## 0. 調査の結果と、この文書の立場

**確認できたこと（出典は末尾）**
- 河本はオートポイエーシスを、動的平衡・自己組織化に続く**第三世代**と位置づけ、境界を自律的に産出する機構を示した点を前進とみなす。システムは**作動**によってのみ存在する（行為存在論）。
- **構造的カップリング**の河本・山下の定式：「構成素の集まりがまとまりとなって構造となるように、**システムの集まりがまとまりとなって新しいシステムが成立する場合**」。つまりカップリングは情報交換ではなく、複数の系の作動が連動して**上位の一つの系**（共生系）になること。
- **二重作動**（『メタモルフォーゼ』）：異質な事象の連動。作動する自己（産出的自己）の運動が、構造的自己（位相的自己）を逸脱して組み替えていく。作動しながら、作動の条件そのものを形成する。
- **能力の形成**：「わかる」と「できる」は別。能力形成は名詞ではなく**動詞の経験**で、やってみることが唯一の方法。発達をリセットし、経験の**可動域**を広げる。「飽きる」ことで別の活動へ移り、戻ると能力が再組織化される。
- 臨床の文脈では、カップリングを**密な間接性**（荒川修作に由来）と呼ぶ。治療者は患者の顕在的な能力ではなく、それを支える**潜在的な作動**を形成する。

**確認できなかったこと**
- 「願い」「楽しい」「意味」を河本が術語として使っている箇所は見つけられなかった。この文書の **c** は、能力形成・経験の可動域・飽きる力から私が組み立てた**拡張**で、河本の語ではない。
- 原典の本文は読めず、書誌・紹介文・二次論文（山下、稲垣）の要約に依っている。

## 1. 土台にした概念

| 概念 | 意味 | 出典 |
|---|---|---|
| 作動 | システムは作動においてのみ存在する。観察される構造ではなく、いま産出し続けている運動 | 河本『オートポイエーシス 第三世代システム』 |
| 産出的自己／位相的自己 | 作動する自己と、その作動が形づくる構造としての自己。前者が後者を逸脱し組み替える | 稲垣による河本の整理 |
| 二重作動 | 異質な二つの作動の連動。作動しながら、作動の条件を形成する | 河本『メタモルフォーゼ』 |
| 構造的カップリング（河本・山下） | 複数のシステムがまとまって新しいシステムになること。情報の受け渡しではない | 山下和也 |
| 密な間接性 | カップリングの臨床的な言い換え。直接は触れないが、作動の条件を互いに密に作り合う | 河本『臨床するオートポイエーシス』 |
| 潜在的な作動 | 顕在的な能力を支える、見えない運動。介入はここに向かう | 同上 |
| 能力の形成 | 「できる」になること。動詞の経験。やってみることでしか起きない | 河本『哲学の練習問題』 |
| 経験の可動域 | 経験がどこまで動けるかの幅。リセットと歩行で広がる | 河本『経験をリセットする』 |
| 飽きる力 | 努力を手放して別の活動へ移ることで、戻ったときに能力が再組織化される | 河本『飽きる力』 |

## 2. 単位：共生系

**単位は、人の系とAIエージェントの作動がカップリングして成立する共生系**です。

- **人**：生きた系であり、意識と身体の作動をもつ。
- **AIエージェント**：自分の物質を作らないので、それ自体はオートポイエーシス系ではない。だが、人の作動に連動して**作動を続ける一つのプロセス**（読む・書く・実行する）ではある。
- **共生系**：両者の作動が連動して、どちらか一方だけでは続かない上位の運動が成立したとき、そこに新しい一つの系が立つ。河本・山下のカップリングの定義そのもの。
- **境界**：共生系の境界は、その運動が続くかどうかで引かれる。構成員の名簿ではない。

ルーマン版との違い：ルーマンでは人もAIも社会システムの環境でした。河本版では、人とAIの作動は共生系の**構成素を産出する運動の一部**で、共生系の内側にあります。ただし、どちらも共生系を外から操作する位置にはいません。

## 3. 三つの運動の循環：a → b → c → a

```
   ┌────────────────────── 産出する ──────────────────────┐
   ▼                                                        │
 a 社会レベルの運動 ──産出する──▶ b 運動を産出する運動 ──産出する──▶ c 願いの産出
 （作動）                        （二重作動・能力の形成）         （次の作動の向き）
```

| 項 | 何であるか | 何を産出するか | 何に依存するか |
|---|---|---|---|
| **a. 社会レベルの運動** | 人とAIが連動して実際に起きている作動。会話、コードの変更、レビュー、デプロイ、振り返り。名詞（成果物）ではなく動詞（起きている運動） | **b** を産出する。運動が繰り返されることで、その運動を可能にする潜在的な作動（手順、型、呼吸、間合い）が形成される | **c** に依存する。向きがなければ運動は始まらない |
| **b. 運動を産出する運動** | 二重作動の層。a の作動が、a の作動の条件（能力、型、カップリングの密度）を組み替えている運動。「できる」になる過程。リハビリで言う潜在的な作動の形成 | **c** を産出する。可動域が広がると、これまで思いつけなかった次の運動が「やってみたいもの」として現れる | **a** に依存する。やってみることでしか形成されない |
| **c. 願いの産出** | 広がった可動域の中で、次にやってみたくなる運動の向き。「より意味がある」「より楽しい」と感じられる方向。意味は評価ではなく、運動の向きとして現れる | **a** を産出する。願いが次の社会レベルの運動を起こす | **b** に依存する。能力が形成されなければ、願いは古い可動域の中にとどまる |

**自己参照**：a を産出する機構（b と c）は a 自身が形成する。外から計画を据え付ける者はいない。
**不安定性**：どれか一つが止まれば三つとも止まる。願いが尽きれば運動は惰性になり、運動が止まれば能力は形成されず、能力が形成されなければ願いは古いままになる。
**飽きる力の位置**：a が同じ運動を繰り返して b の形成が止まったとき、いったん別の運動へ移る（飽きる）ことが、戻ったときの b の再組織化を起こす。循環の中の意図的な中断として置く。

## 4. 人とAIの共生関係：密な間接性

カップリングは「人がAIに指示する」「AIが人に提案する」という受け渡しではありません。**互いの作動が、相手の作動の条件になっている**ことです。

| 観点 | 人の作動 | AIエージェントの作動 |
|---|---|---|
| a で何をしているか | 向きを与え、間合いを取り、引き受ける | 読み、書き、実行し、候補を増やす |
| b で何が形成されるか | AIと組んだときの手順、問いの立て方、任せる型 | 指示文、道具、記憶、権限。人の作動によって組み替えられる |
| c で何が現れるか | 広がった可動域の中で、やってみたい運動 | 願いはもたない。ただし人の願いの可動域を広げる候補を出す |
| 直接触れるか | 触れない。AIの内部には手を入れられない | 触れない。人の意識には手を入れられない |
| 条件を作るか | 作る。AIの作動の条件（前提、記憶、権限）は人の作動から形成される | 作る。人の作動の条件（見える選択肢、手順の速さ）はAIの作動から形成される |

**潜在的な作動への介入**：共生系を良くしたいとき、介入すべきは顕在的な成果（コードの量、速さ）ではなく、b の層、つまり二人で動くときの潜在的な作動です。リハビリで治療者が顕在的な能力ではなく潜在的な作動を形成するのと同じです。

**非対称性**：共生系は対称ではありません。願い（c）を産出するのは人の側で、AIは願いの可動域を広げる役です。ここが「AIが人に代わる」ではなく「共生」である理由になります。ただしこれは河本の記述ではなく、この文書の立場です。

## 6. 判定の問い

1. a は名詞ではなく動詞として言えるか。成果物の一覧ではなく、いま起きている運動として記述できるか。
2. b は見えているか。繰り返しの中で、できるようになったこと（手順、型、間合い）を言えるか。
3. c は b から出ているか。次にやりたいことが、広がった可動域から現れているか。古い可動域の中で願いを回していないか。
4. カップリングは密な間接性になっているか。人がAIの内部を、AIが人の意識を、直接操作しようとしていないか。
5. 介入は潜在的な作動に向いているか。成果の量や速さだけを動かしていないか。
6. 飽きる余地があるか。同じ運動を繰り返して b が止まったとき、別の運動へ移ることが許されているか。

## 7. 図にするときに見せるべきこと

1. a・b・c が三つの運動として、それぞれ別の速さで動いていること。
2. a の運動が b の形を変え、b の形が c の向きを変え、c の向きが a を起こすこと。外から据え付ける者がいないこと。
3. 人とAIの作動が互いに触れず、互いの作動の条件だけを作っていること（密な間接性）。
4. どちらか一方の作動だけでは、共生系の運動が続かないこと。
5. b が止まったとき、c が古い向きのまま空回りし、a が惰性になること。飽きて別の運動へ移ると b が組み替わること。
6. 願い（c）が人の側から出て、AIがその可動域を広げていること。
