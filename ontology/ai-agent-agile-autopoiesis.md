# AIエージェントを含む社会システムの産出メカニズム：ルーマン版オントロジー

AIエージェント前提のアジャイルを、ルーマンの社会システム理論でいうオートポイエーシスとして描き直したものです。前の版は生物学版（Varela・Maturana）の「膜と構成素」に寄っていました。この版は、**社会システムが何を要素として、どう自分を産出するか**を中心に置きます。

## 中核：三項の自己参照ループ（いまはここまでに絞る）

オートポイエーシスの核心は、**産出する機構が、その機構自身によって産出される**ことです。この版では、それを互いに依存する3つの項の輪に絞ります。それぞれの項は前の項から産出され、次の項を産出します。どれか一つが止まれば、3つすべてが止まります。

```
        ┌──────────────── 産出する ────────────────┐
        ▼                                          │
  ① 決定 ──産出する──▶ ② 決定前提 ──産出する──▶ ③ 境界
  （要素）               （構造）                （系／環境の区別）
```

| 項 | 何であるか | 何を産出するか | 何に依存するか |
|---|---|---|---|
| ① 決定 | 生まれた瞬間に消える、決定のコミュニケーション | ② 決定前提。決定についての決定として、次の決定の条件を作る | ③ 境界。境界の内側でしか、候補は決定として接続されない |
| ② 決定前提 | 次の決定を方向づける構造（プログラム、伝達経路、人事） | ③ 境界。何が「この系の決定」とみなされるか、誰の・どの経路の伝達を接続しうるか | ① 決定。決定前提は決定によってしか作られない |
| ③ 境界 | 系と環境の区別。どの伝達の候補が系の中に入りうるか | ① 決定。境界の内側で候補が接続され、決定が生まれる | ② 決定前提。境界の引き方は決定前提が決める |

- **自己参照**：①を産出するのは③、③を産出するのは②、②を産出するのは①です。決定を産出する機構（境界）は、決定前提を介して決定自身が作っています。外から機構を据え付ける者はいません。
- **環境の位置**：人の意識とAIエージェントは輪の外にいて、③の外側から伝達の候補を差し出すだけです。どれが①になるかは③が決め、③の形は②が決め、②は①から作られます。
- **当面は扱わないもの**：相互作用システム、組織文化、適応性、記録。記録は輪が回った跡として残りますが、輪の項には数えません。以下の章はこの3項を詳しく説明したものです。3項より多い依存関係は保留とします。

## 0. 前の版から変えたこと

| 前の版 | この版 | 理由 |
|---|---|---|
| 要素は「決定」。構成素は観測範囲・権限などの部品 | 要素は**コミュニケーション**（組織では決定のコミュニケーション）。部品ではなく、生まれた瞬間に消える**出来事** | ルーマンの社会システムは出来事の連鎖で自分を産出する。出来事には持続がないので、次の出来事が続かなければ系は止まる |
| 人とAIは協働系の「参加者」 | 人の意識もAIエージェントも**系の環境**。言語・記録・道具を介して構造的にカップリングする | ルーマンでは人は社会システムの要素ではない。AIも同じ位置に置き、そのうえで人との違いを明示する |
| 境界は構成素の集まり（空間的な膜のイメージ） | 境界は**意味の境界**。一つひとつのコミュニケーションが「これは私たちの系の出来事だ」と自分で印を付けることで引き直される | 社会システムの境界は物理的な膜ではない |
| 構成素が劣化して作り直される | 構造（期待・決定前提）は、繰り返しで**凝縮**され、失望によって**変わる** | ルーマンで「時間とともに変わる」のは要素ではなく構造 |

## 1. 土台にした理論

| 用語 | 意味 | 出典 |
|---|---|---|
| コミュニケーション | **情報**（何を）、**伝達**（どう・なぜ伝えるか）、**理解**（伝達と情報の差が受け取られること）の三つの選択の統一。理解は、次のコミュニケーションがつながることで初めて成立する。誤解も理解に含まれる | Luhmann『社会システム』、二次資料 |
| 社会システムのオートポイエーシス | 社会システムの要素はコミュニケーションで、コミュニケーションはコミュニケーションのネットワークからのみ産出される。意識や行為は要素ではない | 同上 |
| 出来事としての要素 | 要素は持続しない出来事で、生まれた瞬間に消える。系は次の出来事を続けることでしか存続しない | 同上 |
| 意味 | 現実化したものと、可能なものとの差。次につながりうる可能性の地平 | 同上 |
| 二重の偶発性 | 自分も相手も、別様でありえる。どちらも相手が何をするかに自分の出方をかけている。この不確かさが社会的な系を立ち上げる触媒になる | Parsons → Luhmann |
| 構造＝期待 | 社会システムの構造は、次に何がつながりやすいかの期待。繰り返しで凝縮・確認され、失望に応じて学習的・規範的に扱われる | Luhmann |
| 構造的カップリングと撹乱 | 意識と社会システムは作動的には分かれ、言語を介してカップリングする。環境は撹乱（イリテーション）を与えるだけで、何が起きるかは系の構造が決める | Luhmann、Maturana |
| 組織＝決定のオートポイエーシス | 組織は決定のコミュニケーションで決定を産出する。決定前提（決定についての決定）が次の決定を方向づける | Luhmann『組織と決定』 |
| 不確実性の吸収 | ある決定が次の決定の前提として使われるとき、その根拠は問い直されずに引き継がれる | 同上 |
| 決定前提の種類 | プログラム（条件・目的）、伝達経路、人事。直接は決定できない前提として組織文化 | 同上（種類の一覧は二次資料と筆者の知識による。原典で要確認） |
| 人工的コミュニケーション | アルゴリズムは「考える」ことを目指すより、コミュニケーションする能力を再現するほうが働く。学習するアルゴリズムは、利用者の寄与から**仮想的な二重の偶発性**を作り、誰の考えにもない情報をコミュニケーションの回路に入れて複雑さを上げる | Esposito 2017 |
| AIと組織 | AIが組織に与える影響は、決定前提と決定、系の記憶と環境、組織と相互作用システム、構造的カップリングと緩いカップリング、の四つの区別で捉えられる | Aal 2025 |
| スクラムは閉じた系 | スクラムを自己組織的に安定する閉じた系と見ると、統制は間接的になり、自己拘束を促す力が鍵になる | Lies 2020 |

## 2. 単位：どの系が自分を産出するのか

**単位はチーム（組織）という社会システム**です。人の集まりでも、人とAIの集まりでもありません。

- **要素**：決定のコミュニケーション。たとえば「この変更を入れる」「この項目を次にやる」「これは完成とみなす」。
- **構造**：期待と決定前提。
- **境界**：意味の境界。「チームの決定」として次の決定につながるかどうかで、内と外が分かれる。
- **環境**：人の意識、AIエージェントの計算、コードベース、利用者、市場、他の組織、経済や法などの機能システム。

この系の内側で立ち上がる**相互作用システム**（スプリントのイベント、ペアやモブの場、エージェントとの対話セッション）も、それぞれ独立した社会システムとして区別します。

## 3. 産出のメカニズム

### 3.1 一回の産出

```
撹乱（環境）
  └→ 情報の選択 ── 何が「知らせるに値する差」か
  └→ 伝達の選択 ── 人の発話、AIの出力、コミット、チケット更新
  └→ 理解 ──────── 次のコミュニケーションがつながったときに成立する
        └→ 接続 ── 次の決定・問い返し・拒否・無視
              └→ 構造（期待・決定前提）の確認か変化
                    └→ 次の情報・伝達・理解の選択を方向づける …
```

- 一つのコミュニケーションは、つながった瞬間に過去になる。系が残すのは出来事ではなく、**次をつなぐ構造**と**記録**だけ。
- つながらなかった伝達（読まれないエージェントの出力、反応のないチケット）は、系の要素にならない。
- 拒否も接続である。「その案は採らない」とつながれば、それも系を続ける。

### 3.2 組織での形：決定と決定前提

| 概念 | 意味 | AIエージェント前提での例 |
|---|---|---|
| 決定 | 選ばなかった選択肢も一緒に伝わるコミュニケーション | マージする／しない、スプリントゴールを決める |
| 決定前提：プログラム | 条件プログラム（〜ならば〜する）と目的プログラム（〜のために〜する） | 完成の定義、CIのゲート、プロダクトゴール、エージェントへの指示文 |
| 決定前提：伝達経路 | どこで誰に向けて決定が伝わるか | PR、イシュー、共有ボード、エージェントの出力の行き先 |
| 決定前提：人事 | 誰が決めてよいか | 誰がレビューするか、どのエージェントに何の権限を与えるか |
| 決定できない前提：組織文化 | 直接は決定できず、決定の積み重ねから生まれる | 「AIの出力は必ず人が読む」「テストのない変更は出さない」といった暗黙の型 |
| 不確実性の吸収 | 決定が前提として使われると、その根拠は問い直されずに引き継がれる | マージ済みのコードは、次の作業の前提として疑われずに使われる |
| 系の記憶 | 何を覚え、何を忘れるかの働き | リポジトリの履歴、決定記録、エージェントの記憶ファイル |

**ポイント**：エージェントの指示文、使える道具、権限、記憶ファイルは、組織が自分の決定で作る**決定前提**です。組織は「自分にとってのAIエージェント」を自分で産出し、そのAIの出力を撹乱として受け、また自分の決定につなぎます。

### 3.3 境界が引かれ直す仕組み
- 一つひとつの決定が、「これはチームの決定である」と自分で印を付ける（自己言及）。その印がある出来事だけが次の決定の前提になる。
- 印の付け方そのものも決定前提である。誰が承認すれば決定とみなすか、どの経路を通れば正式か。
- 振り返りやレビューは、系が自分と環境の区別を自分の中で観察する場（二次の観察、再参入）。ここで決定前提が書き換わる。

## 4. AIエージェントの位置

### 4.1 系との関係
| 観点 | 人（意識） | AIエージェント |
|---|---|---|
| 系の要素か | いいえ。環境 | いいえ。環境 |
| 自分でオートポイエーシスか | はい。思考が思考を産出する心理システム | いいえ。自分の作動を自分で産出してはいない。計算は外から起動される |
| カップリングの媒体 | 言語、知覚、身体 | テキスト、ツール呼び出し、リポジトリ、記録 |
| 何を持ち込むか | 意識の撹乱（気づき、違和感、意図） | 仮想的な二重の偶発性。大量の人のコミュニケーションから作られた「別様でありうる」応答 |
| 伝達の担い手になれるか | なれる | なれる。系はその出力を伝達として扱い、理解（接続）するかを選ぶ |
| 責任の帰属 | 帰属できる | 系は帰属先として扱えない。決定として扱うには、人事の前提（誰の決定とみなすか）が要る |

### 4.2 AIが入ると何が変わるか
- **伝達の量**：伝達の候補が爆発的に増える。理解（接続）の容量は人の注意と決定前提で限られるので、系は**何をつながないか**の選択に追われる。
- **仮想的な二重の偶発性**：AIは人の発話の集積から「相手の出方」を作るので、系は相手が誰でもないのに、相手がいるかのように接続を続けられる。系の複雑さは上がるが、その出所を系は観察できない。
- **不確実性の吸収の加速**：エージェントの出力がそのまま次の作業の前提になると、根拠が問われずに引き継がれる連鎖が速く長くなる。
- **境界のぼやけ**：エージェントの出力に「チームの決定」の印が付く条件（人事・伝達経路の前提）があいまいだと、何が系の出来事なのかが分からなくなる。

## 6. スクラムとの対応

| スクラム | この版での位置づけ |
|---|---|
| スクラムチーム | 社会システム（組織）。人もAIも要素ではなく、決定のコミュニケーションが要素 |
| スプリント | 決定を一定の間隔でつなぐ時間の構造。接続が途切れないための期待 |
| スプリントのイベント | 相互作用システム。居合わせる者のあいだで立ち上がる |
| プロダクトゴール、スプリントゴール、完成の定義 | 決定前提（目的プログラムと条件プログラム） |
| プロダクトバックログ | 次に何をつなぐかの期待の一覧 |
| インクリメント | 決定の結果として環境に出た作用。環境にとっての撹乱 |
| レトロスペクティブ | 二次の観察。決定前提を決定し直す場 |
| 自己管理 | 外から決定前提を与えられず、自分の決定で決定前提を作ること |

## 7. 判定の問い

この系がルーマンの意味でオートポイエーシス的に回っているかは、次の問いで確かめます。

1. 要素は何か → 決定のコミュニケーションとして識別できるか。
2. 要素は要素から産出されているか → どの決定も、それ以前の決定を前提として起きているか。
3. 境界は系が引いているか → 「チームの決定」とみなす条件を、チーム自身の決定で決めているか。
4. 環境は撹乱にとどまっているか → 人やAIの入力を、そのまま採用せず、系の前提で選んで接続しているか。
5. 構造は系が変えているか → 決定前提の変更が、系の中の決定（振り返りなど）として起きているか。
6. 記憶は改ざんされないか → 過去の決定の記録を、後から都合よく書き換えられないか。

どれかが「いいえ」になる運用は、外から操作される系（アロポイエーシス）に戻ります。たとえば、外から決定前提を押し付ける、AIの出力を接続の選択なしに自動で採用する、記録を書き換える、といった運用です。

## 8. 図にするときに見せるべきこと

1. 要素は出来事で、生まれた瞬間に消える。次がつながらなければ系は止まる。
2. 一つのコミュニケーションは情報・伝達・理解の三つの選択の統一で、理解は次の接続で成立する。
3. 人もAIも系の外側にいて、伝達の候補を差し込むだけ。どれをつなぐかは系の構造（決定前提）が選ぶ。
4. AIからの伝達の候補は大量で、つながらずに消えるものが多い。
5. 決定が決定前提を作り、決定前提が次の決定を選ぶ。境界はその印付けで引き直される。
6. 記録だけは消えずに残り、記憶として次の選択の材料になる。
